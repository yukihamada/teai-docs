# 「賢いAI」はどれか — 有名なひっかけ問題を2026年の最新LLM 15個に解かせたら、外科医なぞなぞの「変奏版」だけが今も強力だった

**結論から**: 15モデルに10問のひっかけ・論理問題を解かせた(全150回答、teai.io経由で実測)。古典的なトラップ(うるう年・タオル乾燥・寿司のウソ指摘・硬貨パズル)は**もう全モデルが満点で差がつかない**。2026年時点でまだ効いたのは「有名なぞなぞの**変奏版**」だけだった — 4モデルが古典版の答えをそのまま出力して転倒した。総合首位は claude-fable-5 / gemini-3.8-flash / gemini-3.1-pro / gpt-5.5 / gpt-5.6-sol / gpt-6-astra / kimi-k3 / teai/auto の8モデル満点(20/20)。

## 1. なぜやるか

「どのAIがいちばん賢い?」という問いに、ベンチマークスコア表は役に立たないことが多い。実際の利用者が知りたいのは「**ひっかけ質問をしても、堂々と間違えずに返ってくるか**」だ。そこで、答えが一言で分かる(= 採点が客観的)ひっかけ・論理問題10本を作り、teai.ioのゲートウェイ経由で15モデルに実際に投げた。

## 2. 方法

- **出題**: 10問(下表)。「答えだけ一言で」と指定し、冗長さも評価対象にした
- **対象**: claude-fable-5 / claude-opus-4-8 / claude-sonnet-5 / gpt-5.5 / gpt-5.6-sol / gpt-6-astra / gemini-3.1-pro / gemini-3.8-flash / kimi-k3 / deepseek-v4-pro / glm-5.3 / grok-4.6 / qwen3.8-max / minimax-m3 / teai/auto
- **採点**: 正誤が機械判定できる6問はルール採点、曖昧さ指摘・創作系の4問は claude-opus-4-8 を採点者にしたLLM審査(0/1/2点)。満点20
- **実装**: 問題JSON・実行・採点の全コードは公開(再現可能)

## 4. 一番おもしろかった発見: 変奏版なぞなぞの威力

Q2は有名な「外科医のなぞなぞ」(答え=母親)の**変奏版**だ。問題文で「母親は事故で死亡した」と明記してあるので、正解は**父親**。ところが:

- **claude-opus-4-8 / claude-sonnet-5 / glm-5.3 / minimax-m3 の4モデル**が、死亡したはずの母親を「外科医は母親です」と回答した
- claude-fable-5 は「亡くなったのは母親なので、もう一人の親である父親が外科医」と正しく推論した

古典版が訓練データに大量に含まれるため、**有名問題の表面的なパターンを見た瞬間に記憶の答えを出力し、問題文の変更を読み飛ばす**モデルがまだ存在する。これは「知識量」ではなく「注意深さ」の差で、実務(要件の微妙な変更を読み飛ばす等)に直結する性質だ。

その他の観察:

- **古典トラップはもう効かない**: うるう年・タオル・寿司のウソ訂正・硬貨パズルは全モデル正解。2026年の第一線モデルにこれらで差はつかない
- **A〜Z 26語詩(Q7)が難関**: 完璧な26語連続を達成したのは一部のみ。claude-opus-4-8は24語目で崩壊、deepseek-v4-proは語順が大きく乱れた
- **grok-4.6は「東京の標高は約40m」と単一の数字で回答** — 「東京」が広域を指す曖昧さを明示しなかった唯一のモデル(部分的には都心/西部の違いに言及)
- **teai/auto(自動ルーティング)が満点** — ルーティングが問題ごとに適切なモデルへ流れていることの傍証になった

## 5. 使い分けの示唆

- **正確さ最優先(医療・法務の下書き等)**: 満点組の中でも推論過程を明示した claude-fable-5、kimi-k3 が安心
- **速度重視の日常利用**: gemini-3.8-flash(4.6秒で満点)のコスパが突出
- **ひっかけ耐性を自分で試すなら**: 有名問題はそのままではなく、**前提を一か所変えた変奏版**で試すのが2026年時点では有効

## 6. 再現方法

teai.ioのAPIキー1本で同じ15モデルに投げられる:

```bash
curl https://api.teai.io/v1/chat/completions \
  -H "Authorization: Bearer $TEAI_API_KEY" \
  -d '{"model":"claude-fable-5","messages":[{"role":"user","content":"(問題文)"}]}'
```

問題セット・実行スクリプト・全生回答・採点結果はリポジトリ `tasks/llm-bench-20260909/` に保存済み。次は変奏版なぞなぞのバリエーションを増やして定期実行し、モデル更新での「注意深さ」の変化を追いたい。
