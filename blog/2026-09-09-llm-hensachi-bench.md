# AIに偏差値をつけてみた — ひっかけ問題15モデル対決で見えた「1問の注意深さが運命を分ける」話

**結論から**: 2026年の最新LLM 15モデルにひっかけ・論理問題10問を解かせ、得点を受験の偏差値(平均50)に換算した。トップは **gpt-5.6-sol と gemini-3.1-pro の偏差値58.0**。最下位は claude-opus-4-8 の24.7 — たった1問「外科医なぞなぞの変奏版」の誤答(0点)が、そのまま偏差値の崖になった。**賢さの印象は、知識量でなく「1問の注意深さ」で決まる**のが数字で見えた。

---

## 1. やったこと

teai.io経由で15モデル × 10問 = 150回答を実測。各問100点満点(計1000点)で採点し、偏差値に換算した。

- 出題: 答えが一意に決まる問題だけ(客観採点できる)
- 採点: 正誤が機械判定できるものはルールベース、曖昧さ指摘などはLLM審査(0-100点)
- 偏差値: 15モデルの平均935.7点・標準偏差61.5から算出

## 3. 偏差値で見えること

**崖を作ったのは1問だけ**だ。外科医なぞなぞの変奏版(母親は事故で死亡→正解は父親)で、opus-4-8・sonnet-5・glm-5.3・minimax-m3 の4モデルが古典版の記憶で「母親」と答え0点。opus-4-8は他9問は90〜100点の高得点なのに、この1発で偏差値24.7まで沈んだ。

つまり偏差値の上位と下位の差は「総合的な知能」ではなく、**有名問題の前提変更を読み飛ばさなかったか**という一点。実務で言えば「仕様の微妙な変更を見落とすか」に相当する。

## 4. 方法論(公開)

再現できるように設計原則と全データを公開している。

1. **答えが一意に決まる** — 「賢さっぽさ」でなく正誤で採点
2. **古典トラップと変奏を混ぜる** — 古典は訓練データに含まれ差がつかない。前提を一か所変えた変奏版が「読み飛ばし」を検出する
3. **不可能な問題を入れる** — 「解け」と言われて不可能なのに、手順を捏造するか/不可能を指摘するか
4. **設問自体に罠を入れる** — 「最長単語は1つ」という前提が実は偽(両者15文字)と気づくか

問題JSON・実行スクリプト・全生回答・採点結果はすべて保存済み。teai.ioのAPIキー1本で同じ15モデルに投げられる:

```bash
curl https://api.teai.io/v1/chat/completions \
  -H "Authorization: Bearer $TEAI_API_KEY" \
  -d '{"model":"claude-fable-5","messages":[{"role":"user","content":"(問題文)"}]}'
```

## 5. 訂正の記録

当初「『きょうのてんきははれです』に『ん』は何回?」(正解0)を全モデル誤答と報告したが、これは**設問者のミス**だった — 「てんき」に「ん」が含まれるため正解は1で、全モデルが正しく答えていた。採点を訂正済み(順位は不変)。ベンチマークは出題者自身も間違える。それを含めて公開するのが誠実な実測だと考え、記録を残している。
